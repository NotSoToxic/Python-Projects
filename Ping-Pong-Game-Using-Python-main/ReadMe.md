# 🏓 Simple Pong Game in Python
A classic Pong game built using Python's `turtle` module.

## 🚀 Project Overview
This is a simple 2-player Pong game where players control paddles to hit the ball back and forth. Each time a player misses the ball, the opponent scores a point. The game runs in a graphical window created using the `turtle` module.

---

## 🎮 Gameplay
- **Player A Controls:**
  - Move Up: `W`
  - Move Down: `S`
- **Player B Controls:**
  - Move Up: `Arrow Up`
  - Move Down: `Arrow Down`

The first player to score the most points wins!

---

## 🛠️ Tech Stack
- **Language:** Python
- **Library:** `turtle`

---

## 📦 Installation

1. Make sure Python is installed on your system. You can check by running:

```bash
python --version
```
2. Clone this repository or copy the code into a Python file.
3. Install required packages (if not already installed):

```bash
pip install turtle
```
4. Run the Python script:

```bash
python pong.py
```
