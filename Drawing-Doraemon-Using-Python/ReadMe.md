# 🐱 Doraemon with Python Turtle

A fun and creative project to draw **Doraemon** using Python's `turtle` module. This project demonstrates how to use turtle graphics to create complex shapes and animations in Python.

---

## 🎨 Project Overview
This Python script uses the `turtle` library to draw Doraemon, the popular cartoon character. It involves creating shapes, filling colors, and positioning elements precisely to form the character's figure.

---

## 🛠️ Tech Stack
- **Language:** Python
- **Library:** `turtle`

---

## 📦 Installation

1. Make sure Python is installed on your system. You can check by running:

```bash
python --version
```
2. Clone this repository or copy the code into a Python file named doraemon.py.

3. Install the turtle module (if not already installed):

```bash
pip install PythonTurtle
```

Run the Python script:
```bash
python doraemon.py
```

---

## 🎮 How It Works

- The program uses turtle graphics to draw Doraemon.  
- It defines multiple functions to draw different parts, like eyes, face, body, and limbs.  
- The character is drawn sequentially using loops and precise angle movements.  
- The final drawing appears on a turtle graphics window.
