# 🚀 Galaxy Shooter Game

A fun and interactive 2D space shooter game built using Python's Pygame library. In this game, the player controls a spaceship and shoots down enemies while avoiding their approach. The game ends when any enemy reaches the bottom of the screen.

---

## 🎮 Game Features

- **Player Control:** Move the spaceship left and right using the `A` and `D` keys.
- **Shooting:** Press the `SPACE` key to fire bullets.
- **Enemy Movement:** Enemies move horizontally and drop down after hitting the screen boundary.
- **Score Tracking:** Your score increases with each enemy you destroy.
- **Game Over:** If an enemy crosses the threshold, the game ends.

---

## 🖥️ Installation and Setup

### 🔽 1. Clone the Repository

Clone the project using Git:

```bash
git clone https://github.com/yourusername/galaxy-shooter-game.git
```

## 🛠️ 2. Install Python and Pygame

**Python Installation:**
- Make sure Python is installed. Check the version using:
```bash
python --version
```

**Pygame Installation:**
```bash
pip install pygame
```
## 📦 3. Ensure Required Assets Are Available

Ensure the following assets are in the same directory as `galaxy_shooter.py`:

- **Images:**
  - `Space.jpg` – Background image
  - `ufo.png` – Game icon
  - `player.png` – Player spaceship
  - `enemy.png` – Enemy spaceship
  - `bullet.png` – Bullet image

- **Sounds:**
  - `b1.wav` – Bullet firing sound
  - `e1.wav` – Explosion sound

- **Fonts:**
  - `freesansbold.ttf` – Font file for score and game-over text
## 🚀 4. How to Run the Game

1. Ensure all assets and the `galaxy_shooter.py` file are in the same directory.
2. Open the terminal or command prompt.
3. Navigate to the project folder:

```bash
cd path/to/galaxy-shooter-game
```
4. Run the python script
```bash
python galaxy_shooter.py
```

## 🎮 5. Game Instructions

- **Player Movement:**
  - Press `A` to move the spaceship left.
  - Press `D` to move the spaceship right.

- **Shooting:**
  - Press `SPACE` to fire bullets.

- **Objective:**
  - Destroy enemies to earn points.
  - Avoid letting enemies reach the bottom of the screen.

- **Game Over:**
  - The game ends if an enemy crosses the bottom threshold.
